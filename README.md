## 3. Tom e personalidade

Um design moderno, tecnológico e elegante.

## 4. Estrutura da página

- Navbar
- Apresentação inicial
- Sobre mim
- Habilidades técnicas
- Projetos em destaque
- Formação acadêmica
- Contato

A página é desenvolvida em React com Tailwind CSS e organizada em componentes.
